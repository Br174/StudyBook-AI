# StudyBook AI

StudyBook AI è un'app di studio assistita dall'intelligenza artificiale progettata per trasformare libri e documenti in materiali di studio strutturati, chiari e accessibili.

## Obiettivo

Pipeline principale:

**Libro originale → analisi completa → capitoli → paragrafi → riassunti didattici → modalità DSA → libro di studio → esportazione**

## MVP v0.1

- Importazione PDF e TXT
- Estrazione del testo dai PDF
- Riconoscimento automatico di capitoli e paragrafi
- Riassunti su più livelli: Approfondito, Studio, Ripasso
- Versione DSA con struttura più leggibile
- Punti chiave, parole chiave e sezione “Da ricordare”
- Ricostruzione del libro di studio
- Visualizzazione del testo originale
- Lettura vocale tramite Web Speech API
- Salvataggio locale del progetto
- Esportazione PDF, DOCX, HTML, TXT e JSON

## Principio di affidabilità

I riassunti devono usare soltanto il contenuto del documento caricato. Nessuna informazione esterna va inserita senza essere chiaramente separata dal testo originale.

## Stato

Sviluppo iniziale in corso. Questo repository è la versione madre ufficiale del progetto. Il precedente esperimento Replit resta separato e potrà essere usato solo per recuperare eventuali parti utili.
